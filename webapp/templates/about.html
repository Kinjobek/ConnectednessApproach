Loyiha haqida

Bu loyiha ConnectednessApproach R paketining (David Gabauer, 2022) to'liq Python porti va uning asosidagi o'zbek tilidagi veb-ilovadan iborat.

Tuzilma

📁 loyiha/ ├── connectedness/ ← Python kutubxonasi (R paketi porti) │ ├── core.py — IRF, FEVD, Wold, getPartition │ ├── models.py — VAR, QVAR, ElasticNetVAR, TVP-VAR, priors │ ├── measures.py — ConnectednessTable, Time/Frequency/Joint/ExtJoint │ ├── datasets.py — 17 ta ma'lumot to'plami │ └── plots.py — matplotlib grafiklari ├── webapp/ ← Flask veb-ilova (o'zbek tilida) ├── validation/ ← R bilan solishtirish testlari (31/31 ✅) └── target_repo/ ← asl R repozitoriyasi (Git'dan yuklangan)

Kutubxonadan dasturda foydalanish

from connectedness import ConnectednessApproach, load_dataset ds = load_dataset("dy2012") # Diebold–Yilmaz (2012) ma'lumoti dca = ConnectednessApproach( ds["data"], nlag=1, nfore=10, model="TVP-VAR", # yoki VAR / QVAR / LASSO / Ridge / Elastic connectedness="Time", # yoki Frequency / Joint / Extended Joint VAR_config={"TVPVAR": dict(kappa1=0.99, kappa2=0.96, prior="MinnesotaPrior", gamma=0.1)}) print(dca["TABLE"]) # bog'liqlik jadvali print(dca["TCI"]) # dinamik TCI
